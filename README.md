# **Lexius** Code Editor

### ***Lexius** is a lightweight, fast, and customizable code editor built with web technologies. It includes features like syntax highlighting, live preview.*

[![GitHub](https://img.shields.io/badge/v3.4.5-Lexius-8208FB?logo=https://raw.githubusercontent.com/PFMCODES/Lexius/052a1eb26dca6f4e921becee7a979f1bce67e87d/assets/images/favicon.svg&logoColor=fff)](https://github.com/PFMCODES/blinkr-mobile)

## 🚀 Features

- ✨ Clean and modern UI
- 🧠 Built-in syntax highlighting (Monaco-based)
- ⚡ Extenson Support (coming soon)
- 🧩 Plugin support (coming soon)
