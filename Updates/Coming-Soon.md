# What's Coming Soon 🚀

## New Features in Development

### 🤖 AI-Powered Code Assistant (Indu)

- Context-aware code suggestions
- Natural language to code generation
- Automated code reviews and refactoring
- Better integration with the Lexius workflow

### 🌐 Enhanced Web Technologies Support

- Better TypeScript/JSDoc integration
- Live preview for React/Vue/Svelte components
- Built-in bundler for quick prototyping

### 🧩 Better Workspaces

Workspaces are currently in beta and will continue to receive improvements.

- Better workspace management
- Improved project organization
- More workspace-specific features
- Smoother workflows for larger projects

### ⚡ Electron Support

Lexius is getting proper desktop support.

- Electron integration
- Better desktop integration
- More control over the development environment
- A smoother desktop experience

### 🔧 Developer Experience Improvements

- **Multi-cursor editing** across files
- **Git integration** with visual diff
- **Extension marketplace** for community plugins
- **Customizable keybindings** and themes

### 🧠 Caret Integration

Caret is coming to Lexius as the next-generation editor engine.

- Deeper Caret integration
- Better editing capabilities
- Improved editor performance
- More control over the editing experience

> ⚠️ **Experimental:** Caret integration is still under development. Expect bugs, weird behavior, and the occasional "what the hell just happened?" moment.
